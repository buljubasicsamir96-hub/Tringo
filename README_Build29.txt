TRINGO ANDROID – BUILD 29 MOBILNI PATCH

Cilj: korekcija širine i prelamanja poruka u Chat-u za Samsung Galaxy A32, bez izmjene baze i JavaScript algoritma pretrage.

Sadržaj:
- Tringo_Build29.html: HTML sa dodatnim CSS pravilima za Android telefone i Landscape.
- Tringo_Build29_mobile_fix.css: izdvojena CSS pravila.
- Tringo_Build29_apply_patch.py: skripta za primjenu istog dodatka na HTML iz Android projekta.

Napomena: Ovo je izvorni UI patch, nije potpisani APK. Nakon zamjene assets/Tringo.html potrebno je izgraditi APK u Android projektu i instalirati ga na uređaj.
